# Livrables attendus

Chaque étudiant ou binôme doit fournir :

- un compte rendu technique ;
- les captures demandées dans les TP ;
- un rapport d’incident pour les challenges ;
- les réponses aux questions de compréhension.

Modèles disponibles :

```text
livrables/template-compte-rendu.md
livrables/template-rapport-incident.md
```

Captures minimales :

- `Get-ADDomain`
- `nslookup dc01.lab.local`
- structure OU ;
- `Get-SmbShare`
- `gpresult /r`
- événements 4720 / 4728 / 4625 ;
- `repadmin /replsummary` ;
- `setspn -L LAB\SRV01$` ;
- `klist` montrant un ticket `HTTP/srv01.lab.local`.
