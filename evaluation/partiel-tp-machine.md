# Partiel — TP Machine — Windows Active Directory

Durée : 2h

## Contexte

Vous administrez le domaine `lab.local`. L’entreprise souhaite améliorer la sécurité AD et fiabiliser la gestion des utilisateurs.

## Missions

1. Créer trois groupes : IT, HR, Marketing.
2. Créer cinq utilisateurs, dont deux comptes administrateurs séparés.
3. Appliquer une politique de mot de passe stricte.
4. Créer une GPO limitant les outils d’administration aux groupes autorisés.
5. Mettre en place verrouillage après 3 échecs.
6. Configurer l’audit sur comptes et groupes.
7. Produire un mini-rapport.

## Livrables

- captures ;
- commandes ;
- rapport court ;
- justification des choix.
